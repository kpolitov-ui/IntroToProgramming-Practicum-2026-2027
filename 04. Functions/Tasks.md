int multiply(int a, int b)
{
    return a * b;
}

{
    std::cout << squareSum(4, 3);
}

<summary><h3>🟢 Задача 6 · Собствена мини библиотека</h3></summary>

Напишете следните функции, като изберете ***подходящи*** тип на връщане и параметри:

| Функция | Какво прави |
| :------ | :---------- |
| `isDigit` | дали даден символ е ***цифра*** |
| `isUpper` | дали даден символ е ***главна*** буква |
| `isLower` | дали даден символ е ***малка*** буква |
| `isAlpha` | дали даден символ е ***буква*** |
| `isAlnum` | дали даден символ е ***цифра или буква*** |
| `capitalize` | главната буква на дадена малка буква |
| `makeLower` | малката буква на дадена главна буква |
| `parseInt` | числовата стойност на символ-цифра (`'9'` → `9`) |
| `toChar` | символът, съответстващ на число (`9` → `'9'`) |
| `myLog` | логаритъм с ***произволна основа*** |
| `myPow` | степенуване |
| `myCeil` | закръгляне на дробно число ***нагоре*** |
| `myFloor` | закръгляне на дробно число ***надолу*** |
| `myAbs` | абсолютна стойност |

> ❗ **Специални случаи:**
> - `capitalize` / `makeLower`: при символ, който ***не е буква***, върнете самия символ.
> - `parseInt`: при символ, който ***не е цифра***, върнете `-1`.
> - `toChar`: ако числото ***не може*** да бъде превърнато в символ, върнете `'\0'`.
> - `myLog`: числото и основата могат да са само ***естествени*** числа. <ins>**Валидирайте входа!**</ins>
> - `myPow`: степените могат да бъдат само ***цели*** числа.

</details>
